## Entropy Arcade

- Spec: docs/superpowers/specs/2026-10-30-entropy-arcade-design.md
- Plan: docs/superpowers/plans/2026-10-30-entropy-arcade.md (progress ledger: .superpowers/sdd/2026-10-30-entropy-arcade/progress.md)
- Run everything inside `foundation develop`; the passport-sim MCP needs that shell (libudev).
- Core logic tests: `cargo test -p entropy-core --lib` (fast, host-only).
- Do not `cargo check` the app crate directly: `ui/ui` (the `@ui` kit) is generated by `foundation preview`/`sim`/`build`, so bare cargo fails on `@ui/theme.slint`. Use `foundation sim`.
- Disk is tight (~6 GB free after a build): a full sim build of this app needs ~5 GB in `target/`.
- Never log secrets (entropy, words, seed, rolls).
